## Contexte

Les professionnels ouest-africains (freelances, créateurs de contenu, agents commerciaux) ont besoin de séparer vie privée et vie professionnelle sans multiplier les cartes SIM physiques. **NumVirt** propose des numéros virtuels à la demande.

## Le produit

Intégration de l'API **5sim.net** pour l'attribution de numéros virtuels à usage unique ou prolongé, à **300 FCFA/numéro**.

## Architecture technique

| Composant | Technologie |
|---|---|
| Frontend | Vite + React 18 + TypeScript |
| Backend | Express |
| Base de données | PostgreSQL |
| API tierce | 5sim.net |

## Cible

Professionnels soucieux de confidentialité en Afrique de l'Ouest : freelances, vendeurs en ligne, créateurs de contenu.

## Rôle

Conception du produit, intégration API tierce, développement frontend et backend.
