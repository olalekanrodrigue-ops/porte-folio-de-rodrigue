## Contexte

Plutôt qu'un simple Google Forms, ce projet fournit un véritable outil de collecte académique pour interroger les agents et responsables de PADME, dans le cadre du [Mémoire PADME](#mémoire-padme).

## Le produit

- Questionnaire **auto-administré**, envoyé par lien, sans création de compte
- **Mobile-first**, durée cible de 5 à 10 minutes
- Questionnaire **multi-étapes** avec barre de progression, sauvegarde et reprise
- Espace admin sécurisé avec statistiques descriptives et export Excel/CSV

## Architecture technique

| Composant | Technologie |
|---|---|
| Framework | Next.js (App Router) |
| Langage | TypeScript |
| Style | Tailwind CSS |
| Base de données | PostgreSQL |
| ORM | Prisma |
| Déploiement | Vercel + Neon PostgreSQL |

## Rigueur méthodologique et éthique

- Consentement explicite horodaté avant toute collecte
- Aucune conservation d'adresse IP ou de localisation, même hashée
- Référence anonyme générée au format `ENT-AAAA-XXXXXX`
- Positionnement clair comme outil académique indépendant, sans logo ni identité officielle PADME

## Rôle

Conception du cahier des charges, modélisation des données, architecture technique et développement complet.
