## Contexte

Pobè ne dispose d'aucune solution de livraison locale structurée. **Livraison Solo** répond à ce vide en connectant commerçants, livreurs et clients au sein d'une seule plateforme, pensée pour un usage mobile en zone urbaine ouest-africaine.

## Le produit

Une Progressive Web App complète, du cahier des charges au code :

- **Cahier des charges détaillé** définissant le périmètre fonctionnel et les règles métier
- **Prototype HTML interactif** pour valider les parcours avant développement
- **Monorepo complet** en production sur la stack cible

## Architecture technique

| Composant | Technologie |
|---|---|
| Frontend | Next.js 14 |
| Backend | NestJS |
| Base de données | PostgreSQL |
| Temps réel | Socket.IO (suivi de livraison) |
| Paiements | MTN MoMo, Moov Money |

## Modèle économique

- Tarification au kilomètre : **200 FCFA/km**
- Couverture répartie en **5 zones** de livraison
- Commission marchand : **6 %**

## Rôle

Conception produit, cahier des charges, architecture technique et développement complet (frontend, backend, temps réel, intégration paiement mobile).
