## Contexte

Le marché ouest-africain manque de plateformes e-commerce dédiées au segment cosmétique/parfumerie haut de gamme, avec une identité visuelle qui reflète réellement le luxe. **LUMIÈRE** comble cet écart.

## Direction artistique

Une identité visuelle originale baptisée **« Aube africaine »**, construite autour d'une palette distinctive :

- Prune
- Or mat
- Bordeaux
- Crème

## Architecture technique

| Composant | Technologie |
|---|---|
| Backend | Node.js / Express |
| Base de données | PostgreSQL (Neon) |
| ORM | Drizzle |
| Frontend | JavaScript vanilla |

## Fonctionnalités clés

- **Paiement manuel multi-canal** : MTN MoMo, Moov Money, virement UBA
- **Système de suivi de commande** par code unique (format `X7K2-P9MQ`)

## Rôle

Direction artistique, architecture backend, modélisation de données et intégration du parcours de paiement adapté aux moyens de paiement locaux.
